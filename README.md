## SWYNEX Task 1: Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing the Sample Superstore dataset for data analysis using Python and Pandas.

## Dataset
The dataset contains sales information, including shipping mode, customer segment, country, city, state, category, sales, quantity, discount, and profit.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Performed
- Checked and handled missing values.
- Checked for duplicate records and removed duplicates where required.
- Checked numerical columns for invalid values.
- Verified data types, including Postal Code.
- Validated sales, quantity, discount, and profit values.
- Saved the cleaned dataset as `SampleSuperstore_Cleaned.csv`.

## Files Included
- `Sales_data_cleaning.ipynb` — Python notebook containing the cleaning process.
- `SampleSuperstore_Cleaned.csv` — cleaned dataset.

## Result
The cleaned dataset was saved successfully. Final validation showed zero missing values and no negative sales, non-positive quantities, or invalid discount values according to the checks performed.
